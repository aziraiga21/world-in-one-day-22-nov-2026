# The World in One Day

An illustrated 1024 × 1024 front page for Sunday 22 November 2026, with 37 supplied stories across six regions. Pillow draws the illustrations, type, and numbered world map. The copy, dates, and attributions come from the entry brief.

- Run `python3 draw.py` to regenerate `entry.png` with Pillow and the local fonts.
- Run `python3 main.py` to copy the PNG into `MAKEFUN_OUTPUT_DIR`, which defaults to `output`.
